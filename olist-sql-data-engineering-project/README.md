## Project Overview

This project demonstrates end-to-end SQL-based data engineering and analytics using the Brazilian Olist E-Commerce Dataset.

The project includes:

- Database design and normalization
- Data quality assessment
- Data cleaning
- Advanced SQL analytics
- Window functions
- CTEs and recursive CTEs
- Stored procedures
- Query optimization
- Performance tuning with indexing

---

## Dataset

Source:
Olist Brazilian E-Commerce Dataset

Tables:

- customers
- orders
- order_items
- order_payments
- order_reviews
- products
- sellers
